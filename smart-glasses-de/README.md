# Newagent: Smart Glasses — German Market (20 Nov 2026)

This package contains a six-stage **research → strategy → copywriting → prototype → QA → final review** workflow. It represents a concept/prototype rather than a launched product or completed market validation.

## Contents

- `01-research.md` — current market overview, sources, competitors, German constraints.
- `02-strategy.md` — WERKBLICK positioning, target customers, six-week pilot and GTM experiment.
- `03-copywriting.md` — German language landing-page/pitch copy.
- `04-prototype/index.html` — fully self-contained interactive static website. Open the file in a browser.
- `05-qa-report.md` — structural and real-browser checks.
- `06-final-review.md` — critical integration, risks, next actions and go/no-go.
- `preview-desktop.png`, `preview-mobile.png` — real Chromium renders.

**Notice:** All claims of future capabilities are conditional and hypothetical. No customer interviews, deployments, partnerships, device testing or commercial sales were performed. The WERKBLICK name is not trademark-cleared.
